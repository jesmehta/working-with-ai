# Coding with AI

A static HTML slide deck — 23 principles for using AI as a coding collaborator without
losing legibility, editability or independence — plus a closing synthesis slide. It is the
companion site to [Working With AI](../working-with-ai), sharing the same visual language
(Bree Serif headlines, Comfortaa body text, an ink-wash sumi-e aesthetic on a cyan/lavender/
blue-violet pastel background with neon accents) but built around a different content
structure: 7 thematic groups instead of a flat list, and richer components (code blocks,
principle/takeaway callouts, tag pills) to hold denser technical content.

## Origin

Content is adapted from [`working-with-ai-for-code-content-structure.md`](./working-with-ai-for-code-content-structure.md),
kept in this repo as the source of truth for the 23 principles, their grouping into 7 themes,
and the two closing "Core Principle" / "Companion Principle" statements. The only deliberate
change from that source is the site title: **Coding with AI** (rather than the file's own
working title) is used throughout `<title>` tags, the landing page `<h1>`, and page titles.

The site was generated by `gen.py`, a Python script that renders all HTML from structured
content data rather than hand-authoring 24 near-identical pages. Re-running it after editing
`gen.py` regenerates every page consistently (nav links, sidebar, page counters, TOC groupings
all stay in sync automatically).

## Structure

```
index.html          Landing page — hero, intro, Core/Companion Principle, grouped TOC
01.html – 23.html    One principle per page, grouped under 7 themes (see below)
24.html              Closing synthesis: all 23 principles connected to the 5
                      responsibilities from page 23, via a live-computed diagram
style.css            Shared design system (typography, palette, components, layout)
background.js        Generative canvas background — one effect per page, not cycling
sidebar.js           Contents drawer: push-layout on desktop, overlay on mobile
connectors.js        Draws the bezier connector diagram on page 24 (positions computed
                      live from the DOM, redrawn on resize and on sidebar toggle)
gen.py               Generator — content data + templates; source of truth for all pages
enso.svg.txt         Pre-generated ink-circle (ensō) SVG markup shared by every page
```

## The 7 groups (23 principles)

1. **Start With Intent** — 1–3
2. **Make the Project Legible** — 4–7
3. **Structure for Human Editing** — 8–11
4. **Build Tools for Yourself** — 12–14
5. **Work Safely with AI-Generated Code** — 15–19
6. **Build Toward Independence** — 20–22
7. **Summary** — 23 (five responsibilities), 24 (closing synthesis)

## Design system

- **Type** — Bree Serif for headlines and pull quotes, Comfortaa for everything else, loaded
  via `<link rel="preconnect">` + stylesheet (not a CSS `@import`, which blocks first paint).
- **Palette** — cyan/lavender/blue-violet pastel wash (`.bg-wash`, a `position:fixed` div
  behind the canvas, sized in viewport units so it doesn't fall short on long pages) with
  neon magenta (`--seal`), cyan (`--neon-cyan`), violet (`--violet`) and electric blue
  (`--accent-blue`) accents.
- **Generative backgrounds** — three effects (`bounce`, `flowfield`, `subdivision`), assigned
  one per page via `data-mode` on `<canvas id="bg">` and never cycling at runtime. All three
  render as semi-transparent ink strokes so the pastel wash stays visible underneath.
- **Ensō** — a hand-generated ink-circle SVG in the lower-right corner of every page, subtly
  breathing via CSS animation.
- **Sidebar** — lists all 23 principles grouped by theme, current page highlighted. Defaults
  open and pushes page content aside on desktop (≥861px); collapses to an overlay drawer with
  a dimming backdrop under 861px, default closed there. The open/closed state lives as a single
  `sidebar-open` class on `<html>`, set synchronously by an inline script in `<head>` so there's
  no flash of the wrong layout before the external scripts load.
- **Components** (`style.css`, used from `gen.py`) — `.card` (weak/better and labelled-row
  comparisons), `.quote`, `.principle` (Core/Companion Principle callouts), `.takeaway`,
  `.codeblock` (monospace, for JSON/file-tree/config snippets), `.pillrow` (tag-style sets
  with no implied sequence), `.bullets`, `.levels` (numbered definition list), `.flow`
  (arrow-connected step sequence).

## Page 24: the closing synthesis

Rather than a static "gathering" graphic, page 24 measures the real DOM positions of each
principle `<li>` and each of the five theme cards (Define / Record / Structure / Inspect /
Decouple — the same five responsibilities introduced on page 23) and draws colored cubic-bezier
curves between them in an absolutely-positioned SVG overlay. The mapping is many-to-one:
several principles feed more than one theme (e.g. principle 19, Version Control, feeds both
Inspect and Decouple). Principle 23 is left intentionally unconnected — it's the summary the
diagram is built from, not an input to it. The diagram redraws on window resize and whenever
the sidebar's push-layout changes the available width (watched via a `MutationObserver` on
`<html class="sidebar-open">`).
